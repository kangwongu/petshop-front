# Project Constitution

## 목적

- petshop-back API를 소비하는 게스트 전용 커머스 프론트엔드를 구현한다.
- petshop-frontend-prev(이전 프로토타입)의 **디자인, 브랜드("뚱이요미 샵"), 콘텐츠**를
  그대로 재현하되, 발견된 아키텍처 이슈(전체 클라이언트 컴포넌트, 디자인 토큰/raw hex
  혼용)는 개선한다. 브랜드/카테고리명/데모 상품 콘텐츠는 petshop-back의 실제 카탈로그
  도메인(일반 반려용품)과 무관하게 원본 그대로 유지한다.

## 성공 기준

- 로컬 환경에서 홈 → 상품 상세 → 장바구니 → 주문서 → Toss 결제 팝업 → 결제 완료
  플로우가 끊김 없이 동작한다.
- petshop-back의 Phase 4(프론트엔드 연동 검증) 요구사항을 충족한다.

## 제약사항

- **유지보수 인원**: 1명 (본인)
- **API 계약**: petshop-back의 TR-06에 따라 고정된 계약을 따른다 (임의 변경 불가,
  계약 상세는 `specification.md`의 TR-06 참고)
- **인증 없음**: 회원가입/로그인 없이 게스트 buyer 정보만 사용
- **서버 장바구니 없음**: 장바구니는 클라이언트(localStorage) 상태로만 관리
- **카테고리 API 없음**: 카테고리 목록은 프론트엔드에 하드코딩
